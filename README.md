# Creative Strategy Portfolio

React + Vite + TypeScript + Tailwind CSS portfolio site built for deployment on Vercel.

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Deploy to Vercel via GitHub

1. Create a new GitHub repo.
2. Upload/push this folder to the repo.
3. Go to Vercel → Add New Project → Import GitHub repo.
4. Framework preset: Vite.
5. Build command: `npm run build`.
6. Output directory: `dist`.
7. Deploy.

## Customize before publishing

- Replace GitHub and LinkedIn links in `src/App.tsx`.
- Update email if needed.
- Edit project copy in `src/data/projects.ts`.
- Replace images in `public/assets/projects`.
